# Team assets

The CEO portrait is stored here as:

```
public/images/ceo-akash-gill.jpg
```

It is the supplied photograph, copied byte-for-byte (1254×1254) and used by
`components/leadership.tsx` on the home page and the About page. It is not
recoloured, cropped in the source, or replaced.

The image is displayed with `object-fit: cover` in a 4:5 frame, so the crop is
responsive and keeps the face centred.

The `public/team` folder is unused and can be deleted.
